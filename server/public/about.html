Tvoy Apart Content Bot

Внутренний сервис автоматизации контента для канала «Tvoy Apart 24/7» на YouTube — публикация коротких видео об апартаментах посуточной аренды «Твой Апарт 24/7» (Москва, Чистые Пруды).

Сервис используется одним владельцем канала для публикации собственных, заранее подготовленных и утверждённых видеороликов по расписанию. Доступ к YouTube-аккаунту используется только для загрузки видео на единственный принадлежащий владельцу канал — сервис не работает с чужими каналами и не передаёт доступ третьим лицам.
