Настоящая политика описывает, как сервис Tvoy Apart Content Bot (далее — «Сервис») обрабатывает данные при использовании Google API, в частности YouTube Data API v3.

Какие данные Google запрашиваются

Сервис запрашивает только один разрешённый доступ (scope) Google API: https://www.googleapis.com/auth/youtube.upload — право загружать видео на YouTube-канал, авторизованный владельцем. Сервис не запрашивает доступ к чтению личных данных аккаунта Google (почта, контакты, диск и т.п.) и не запрашивает доступ к чужим каналам.

Как используются данные

Полученный доступ используется исключительно для автоматической публикации собственных видеороликов оператора (рекламный/информационный контент об апартаментах «Твой Апарт 24/7») на канал «Tvoy Apart 24/7» по заранее утверждённому расписанию. Видео перед публикацией готовятся и одобряются лично оператором — Сервис не генерирует и не публикует контент без предварительного утверждения.

Хранение данных

Токен доступа (refresh token) хранится в зашифрованном виде в переменных окружения сервера и не передаётся и не раскрывается третьим лицам. Сервер физически расположен на арендованном VPS, доступ к которому имеет только оператор.

Передача данных третьим лицам

Сервис не передаёт, не продаёт и не раскрывает какие-либо данные, полученные через Google API, третьим лицам. Единственное действие, выполняемое от имени пользователя, — загрузка видео на его собственный YouTube-канал.

Отзыв доступа

Оператор может в любой момент отозвать доступ Сервиса к своему аккаунту Google через страницу myaccount.google.com/permissions .

Соответствие требованиям Google

Использование и передача данных, полученных через Google API, соответствует Google API Services User Data Policy , включая требования ограниченного использования (Limited Use).
