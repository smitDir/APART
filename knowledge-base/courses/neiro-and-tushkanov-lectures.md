## 1. `35b829d4` — «Составление запросов для визуальных нейросетей»

**Автор:** Тушканов Евгений. 20 стр. (весь файл).

**О чём:** Юридическая сторона генеративных нейросетей для фото в РФ — авторство ИИ-контента, дипфейки, товарные знаки, легальные обходы ограничений платформ. Мало техники промптинга, в основном право.

**Единственный переиспользуемый приём** (замена прямого упоминания бренда на описание):
```
Не "логотип Nike", а "изображение современных кроссовок с узнаваемым
изогнутым логотипом на белом фоне"
```

**Фреймворки:** нет.

**Резюме:**
- ИИ — инструмент, а не автор; ответственность несёт оператор/пользователь (ст. 1274, 1301, 1484 ГК РФ, ст. 207.1 УК РФ за дипфейки).
- Штраф за незаконное коммерческое использование ИИ-контента — до 5 млн руб.
- Обзор инструментов генерации: Kandinsky 3.1, GigaChat, Qwen, Шедеврум, YandexGPT, LMArena, Napkin (текст → визуал).
- Практические задания на замену лиц/логотипов — установочные, без шаблонов.

**Relevance:** (c) filler/немного нового — юридический контент специфичен для РФ, полезен как справка, но не как промпт-библиотека.

## 2. `ab779dc9` — «Внесение правок в готовое изображение»

**Автор:** Тушканов Евгений. 6 стр. (весь файл).

**О чём:** Список из 5 практических упражнений на генерацию/редактирование изображений (стили, ракурсы, эмоции персонажа, комиксы).

**Задания (можно переиспользовать как шаблоны техзаданий для фото/иллюстраций):**

1. Один и тот же сюжет нарисовать в трёх кардинально разных стилях.
2. Создать изображение, где магический артефакт интегрирован
   в современный технологичный мир.

   ракурсами и композициями.

   архитектурных направлений.
5. Создать портрет одного и того же персонажа, испытывающего

**Фреймворки:** нет.

**Резюме:**

- Полезно как шаблон ТЗ для генерации серии изображений одного персонажа/товара в разных вариациях (актуально для карточек товаров — лампы, куклы, платья).

**Relevance:** (a) generic — применимо к любой нише, где нужны консистентные серии изображений товара/персонажа.

## 3. `b250a685` — «Как сделать агента автономным» (лекция 4, серия НЕЙРО)

**27 стр., весь файл.**

**О чём:** Переход от разового диалога с агентом к регулярным (автономным) задачам по расписанию — «агент как личный секретарь».

**Ключевой переиспользуемый шаблон (превращение разовой задачи в регулярную):**
```
Шаг 1 (проверить разово):
«Проверь почту и составь короткую сводку по непрочитанным письмам».

Шаг 2 (сделать регулярной):
«Сделай эту задачу регулярной: каждый будний день в 9:00 утра
проверяй почту, составляя короткую сводку по новым письмам
и присылай мне её в чат.»
```

Общая формула: **«сделай это регулярной задачей с таким расписанием»** — одной фразой любую разовую задачу превращаешь в автономную.

**Фреймворк — матрица приоритизации задач для автоматизации (2×2):**
| | Легко проверить | Сложно проверить |
|---|---|---|
| **Часто** | Начните здесь (сводки, отчёты, напоминания) | Можно автоматизировать, но сначала с проверкой перед отправкой (ответы клиентам, посты) |
| **Редко** | Автоматизировать стоит, эффект медленнее (ежемесячные отчёты) | Пока не сюда — оставить в диалоговом режиме (сложные переговоры, креатив) |

**Таблица подсчёта выгоды** (шаблон для ROI-анализа рутинных задач):
```
Задача | Как часто | Занимает | Часов/нед. | Отдать агенту?
Проверка и сортировка почты | ежедневно | 15 мин | ~1.25ч | Да
Сводка по продажам/метрикам | раз в неделю | 30 мин | 0.5ч | Да
Ответы на типовые вопросы клиентов | ежедневно | 20 мин | ~1.7ч | Да
Публикация контента в соцсетях | 3 раза в нед. | 20 мин | 1ч | Да
```

**Резюме:**
- Автономность = задача, которую уже умеете формулировать + расписание её выполнения — не отдельная суперспособность, а естественное продолжение навыка постановки задачи.
- Примеры применения: агент-секретарь с напоминаниями, мониторинг Telegram/RSS/VC.ru/Habr/Hacker News с ежедневной сводкой и генерацией постов, AI-аналитик бизнеса (ежедневный отчёт по финансам/маркетингу/заявкам вместо ручного сведения 10+ таблиц — экономия 250 тыс. руб. на разработке такого бота).
- Совет: начинать с 1-2 задач, дать поработать неделю, потом добавлять следующие.

**Relevance:** (b) Claude-Code/agent-specific, но сама формула «сделай задачу регулярной с расписанием X» и матрица приоритизации — переносимы на любой бизнес (апартаменты: автосводка бронирований, автонапоминания об уборке/заезде).

## 4. `bd6305be` — «Как правильно ставить задачу агенту» (лекция 3, серия НЕЙРО)

**49 стр.** Содержит идею-галерею (~90+ карточек продуктовых идей для разных ниш) и универсальный **5-шаговый фреймворк вайб-кодинга**.

### 5-шаговый фреймворк создания цифровых продуктов через ИИ (по методологии создателя Claude Code, Бориса Черни)

1. **ИДЕЯ** — формулируете ЧТО, ДЛЯ КОГО и ЗАЧЕМ
2. **ИССЛЕДОВАНИЕ** — смотрите существующие примеры
3. **КРИТИКА** — просите ИИ оценить идею, проверить факты
4. **ПЛАН** — составляете структуру продукта (разбивка на 3-5 этапов)
5. **РЕАЛИЗАЦИЯ** — собираете через AI пошагово (одна задача = один промпт)

**Шаг 1 — шаблон формулировки идеи:**
```
Я создаю ЧТО для КОГО чтобы решить проблему КАКУЮ

Пример: «Я создаю агента для расчета сметы ремонта для владельцев
квартир, чтобы они за 2 минуты узнали примерную стоимость»
```

**Шаг 2 — промпт для параллельного исследования (запуск нескольких агентов):**
```
Запусти параллельно 3-5 агентов в интернет для глубокого исследования
следующих категорий продуктов: Telegram/WhatsApp боты, AI-ассистенты
(чат-боты, помощники), AI-агенты (автономные системы), Автоматизации
(n8n, Make, Zapier-подобные)

Инструкции для агентов. Каждый агент должен:
1. Искать реальные работающие примеры на русском и английском рынках
   (Product Hunt, Reddit, Indie Hackers, Telegram-каналы, YouTube-кейсы)
2. Находить продукты, запущенные за последние 6-12 месяцев
3. Приоритет — продуктам, сделанным соло-разработчиками или маленькими
   командами без больших бюджетов

Формат ответа по каждому продукту. Для каждого найденного продукта дай:
- Название + суть (1 фраза, что делает)
- Ключевой функционал и путь пользователя (3-5 шагов от входа до результата)
- Модель монетизации (подписка/разовая оплата/freemium/комиссия —
  с конкретными цифрами, если есть)
- Сложность реализации: 🟢 просто / 🟡 средне / 🔴 сложно
- Как сделать через Claude Code
- Какой стек/инструменты использовать
- Какие API/сервисы подключать

* Как адаптировать под мою нишу (AI-образование, инфобизнес,
  продажи через Telegram)

Создай файл Research.md с результатами исследования для дальнейшей
разработки
```

**Шаг 3 — промпт для критики идеи (найти слабые места ДО начала работы):**
```
Я хочу создать [ваша идея из Шага 1].

Проанализируй мою идею и ответь:
1. Что может не сработать?
2. Чего не хватает для успеха?
3. Какие секции/элементы обязательно должны быть?
4. Какие типичные ошибки делают в таких сайтах?
5. Как улучшить мою идею?
```

**Шаг 4 — План:** описываем итоговый результат → разбиваем на 3-5 этапов → каждый этап = одна задача для ИИ (аналогия — «собирать LEGO по инструкции»).

**Шаг 5 — Реализация:** одна задача = один промпт; берём этап из плана → пишем промпт → проверяем → следующий этап.

**Резюме и афоризмы из слайдов** (полезны как рамка для объяснения клиентам/себе):
- «Это как строить дом без системы: купил кирпичи, начал класть стены, забыл фундамент — всё развалилось». С системой: сначала чертёж → потом фундамент → потом стены.
- «Шеф-повар не придумывает борщ заново каждый раз. Он изучает 10 лучших рецептов и собирает свой» (про этап Исследование).
- «Лучше найти проблему за 3 минуты в чате с ИИ, чем через 5 часов работы обнаружить, что ваш продукт никому не нужен» (про этап Критика).

**Идея-галерея (нерелевантные конкретные примеры, но структура категорий полезна):** продукты сгруппированы по нишам — «для тех, кто оказывает услуги» (бот-администратор Telegram, калькулятор стоимости, мини-CRM), «для тех, кто обучает» (ИИ-репетитор, обучающее мини-приложение, бот-диагност), «для тех, кто продаёт» (витрина товаров в Telegram, парсер цен конкурентов, бот-продажник), «для тех, кто продаёт экспертизу» (ИИ-ассистент с экспертизой, лендинг-генератор заявок, бот для поиска клиентов). Это шаблон категоризации продуктовых идей, применимый к вертикалям заказчика (аренда квартир, лампы, куклы, свадебные наряды, детский туризм, красота, юруслуги) — под каждую нишу можно сгенерировать аналогичный список через тот же 5-шаговый фреймворк.

**Relevance:** (a) generic prompting technique — весь 5-шаговый фреймворк и три промпта (Идея/Исследование/Критика) полностью применимы к любой из 7 вертикалей бизнеса заказчика. Раздел про параллельных агентов — (b) Claude-Code specific.

## 5. `bf224e96` — «Усиление промптов: как заставить AI работать на все 100%» (1.2, Нейроуниверситет прибыльных профессий)

**60 стр., весь файл.** Самый насыщенный шаблонами файл. Продолжение серии про структуру CRAFT (пройдена на предыдущем уроке): Context, Role, Action, Format, Tone.

### Суперсила 1: Chain prompting (подсказки по цепочке)

Нельзя просить всё одним промптом — разбивать на шаги. Пример (продающий пост про самокат):

```
❌ Плохо: «Напиши продающий пост про самокат»

✅ Хорошо:
Шаг 1: «Какие 3 главных страха родителей при покупке самоката?»
Шаг 2: «Как наш самокат решает каждый страх? Конкретно»
Шаг 3: «Теперь собери продающий пост про наш самокат,
        начиная с главного страха»
```

**Универсальный шаблон практики (3 шага для любого бизнеса):**
```
Шаг 1: «Назови 3 главные проблемы моих клиентов при выборе [ваш продукт]»
Шаг 2: «Как конкретно [ваш бизнес] решает каждую проблему?
        Приведи точные факты»
Шаг 3: Создай продающий пост, начиная с главной проблемы.
        Добавь конкретные цифры
```
Критерии успеха: в каждом шаге конкретные цифры, нет общих фраз типа «высокое качество», есть измеримый результат.

### Суперсила 2: Метод инверсии

Вместо «как привлечь клиентов» — спросить «почему клиенты уходят».

```
Было: «Как сделать крутой сайт?»
Стало: «Перечисли 5 главных причин, почему люди закрывают сайт
        в первые 3 секунды»

Инверсия (кофейня): «Представь, что ты тайный посетитель. Назови
5 вещей, из-за которых ты больше не вернёшься в кофейню»
```
Ещё примеры по нишам:
```
Магазин одежды: ❌ «Как увеличить средний чек?»
                ✅ «Почему люди уходят с одной вещью вместо комплекта?»
Онлайн-курсы:   ❌ «Как повысить конверсию в покупку?»
                ✅ «Назови все причины, почему люди бросают курс
                    на первом уроке»
```
**Практика:** возьмите главный запрос → переверните наоборот → задайте вопрос «Как это изменить?» → сравните оба варианта в GPT.

### Суперсила 3: Множественные итерации

Принцип: Версия 1 → Анализ → Версия 2 → Анализ → Финал (аналогия с фотошопом — сначала общая картинка, потом яркость/контраст/детали).

```
1. Промпт для анализа:
«Проанализируй этот текст как маркетолог с 10-летним опытом.
 Что можно улучшить?»

2. Промпт для улучшения:
«Переработай текст с учетом замечаний. Сделай его сильнее»

3. Финальный промпт:
«Сравни две версии. Что стало лучше? Что еще можно улучшить?»
```

### «4 специи» (фишки усиления промптов)

1. **Угрозы:**
```
«Проверь текст так, будто от этого зависит успех всего бизнеса.
 Если текст слабый — тебя уволят»
```
2. **Внедрение шкалы:**
```
«Оцени каждый абзац по шкале 1-10. Переписывай, пока не будет
 минимум 9/10»
```
3. **Денежная мотивация:**
```
«Ты маркетолог. Если ты напишешь текст хорошо с первого раза —
 дам тебе бонус 1000 долларов»
```
4. **Английский язык / поиск данных в интернете:**
```
«Перед написанием статьи найди последние тенденции на рынке кофе
 и данные о поведении потребителей».
```

**Финальный микс-пример (можно комбинировать техники):**
```
1. «Этот текст пойдет на главную рекламу года. Оцени его
    по 10 критериям» (угроза + шкала)
2. "You're a $1000/hour consultant. Analyze this text and
    improve it" (деньги + английский)
3. «Ты топовый маркетолог. Найди свежие данные по рынку.
    Оцени текст по шкале и переделай на уровень premium»
    (финальный микс всех техник)
```

**Резюме:**
- CRAFT-фреймворк упомянут как база («печатные буквы»): Context/Role/Action/Format/Tone, пример — «Я художник, продаю картины» / «Ты опытный маркетолог» / «Напиши пост» / «Для Instagram» / «Молодёжный».
- Это урок про «прописные буквы» — техники усиления поверх базовой структуры CRAFT.
- Анонс следующего урока: zero-shot vs few-shot, «эксперт наоборот», контекстные якоря.

**Relevance:** (a) полностью generic prompting techniques — все шаблоны в этом файле напрямую переиспользуемы для промпт-библиотеки заказчика (маркетинг для любой из 7 вертикалей, тексты, чат-боты, анализ отзывов и т.д.). Это самый ценный файл из шести для практической копилки промптов.

## 6. `745cf343` — «Что такое скилл агента. Как он устроен» (продолжение, стр. 16–45, серия НЕЙРО)

Ранее прочитаны стр. 1-15 (архитектура скиллов/плагинов Claude Code). Ниже — новое со стр. 16 до конца файла (стр. 45).

### Три «специалиста» (готовые скиллы/паттерны для агента)

**1. Разведчик** — уже встроен в Claude Code, ничего ставить не нужно.
- Что делает: идёт в Google по запросу, открывает сайты и читает их, возвращается с таблицей фактов.
- Слова-триггеры: «найди», «поищи», «что у конкурентов», «посмотри на сайте», «свежие данные».
- Пример: «Найди 5 языковых школ в моём городе и что у них на сайтах».

**2. Интервьюер** (скилл `discovery-interview`) — превращает туманную идею в чёткое ТЗ.
- Что делает: проводит 7-фазное интервью, вопросы с вариантами ответа (не «расскажите мне всё»). На выходе — файл-спецификация на 5 страниц.
- Слова-триггеры: «помоги сформулировать заказ», «собери ТЗ», «опиши техзадание», «нужна спецификация».
- Пример: «Помоги собрать ТЗ для нейросотрудника языковой школы».

**3. Разработчик** (скилл `fullstack-developer`) — пишет код, вы проверяете глазами.
- Что делает: прототип сайта/лендинга, форма записи, скрипт автоматизации, Telegram-бот, интеграция заявка → таблица.
- Слова-триггеры: «сделай сайт», «добавь форму», «нужна страница», «напиши скрипт», «поправь код».
- Пример: «Сделай прототип посадочной с формой записи».

### Плагин Superpowers (методология поверх агента)

Проблема без методологии: агент торопится — сразу пишет код без вопросов, сразу даёт ответ, не разобравшись, не проверяет себя в конце. Superpowers заставляет идти по этапам: идея → план → исполнение → проверка.

**3 главные команды:**
```
/brainstorm — разобраться в задаче перед началом
  Когда: заказчик пришёл с размытой идеей
  Результат: документ концепции

/write-plan — превратить идею в пошаговый план
  Когда: концепция понятна, непонятно «с чего начинать»
  Результат: пошаговая инструкция (микрозадачи по 2-5 минут,
  для каждой — файл, код, как проверить)

/execute-plan — пройти по плану и проверить себя
  Когда: план одобрен
  Результат: готовое решение, прошедшее самопроверку
  (при ошибке — сам исправляет, не спрашивая по мелочам)
```

### Установка скилла — «фраза без терминала»

Главное правило блока: никаких терминалов, никаких технических команд — только фразы прямо в окне Claude Code.

**4 шага установки одного скилла:**
```
1. Заходите на skillsmp.com, находите нужный скилл в каталоге
2. Копируете адрес репозитория (кнопка «Copy» на странице скилла)
3. Пишете фразу в окне Claude Code:
   «Поставь скилл вот этот: [адрес] в папку .claude/skills моего проекта»
4. Claude делает всё сам — скачивает, кладёт в нужную папку
```
**Пример реальной фразы для установки (полностью готовый шаблон):**
```
Поставь мне скилл в папку этого проекта. Скилл лежит по этой ссылке
https://github.com/parcadei/Continuous-Claude-v3/tree/main/.claude/skills/discovery-interview
```

**Установка плагина Superpowers** — через слэш-команду `/plugins` в окне Claude Code (менеджер плагинов), поиск «superpowers» (официальный плагин Claude). Внимание: ставится глобально в `~/.claude/plugins/` — доступен во всех проектах, а не только в одном.

### До/После пример (иллюстрация ценности команды специалистов)

Заказ: «Хочу разработать Агента для языковой школы "ABC English", который будет помогать собирать заявки на пробный урок и решит проблему владельца — теряет 40% заявок по выходным».

- Один агент без методологии → общий расплывчатый ответ («подумайте над целевой аудиторией, сделайте лендинг...»).
- Команда специалистов: 15 мин Интервьюер (25 вопросов с вариантами → спецификация на 5 стр.) + 10 мин Разведчик (5 сайтов школ → таблица) + 15 мин `/brainstorm` уточняет концепцию с находками Разведчика → документ концепции.

**Резюме:**
- Три специалиста + Superpowers = минимальный «стартовый комплект» для агентства/фрилансера, работающего с Claude Code для клиентов.
- Домашнее задание: установить себе скиллы для работы в Claude Code (полезны при любой работе с вайб-кодингом, даже без своего агента).

**Relevance:** (b) Claude-Code/agent-architecture specific — это чисто техническая инструкция по установке и использованию скиллов/плагинов Claude Code, не переносится напрямую на промпт-копирайтинг для других вертикалей, но крайне полезно как операционный процесс для самого владельца бизнеса при разработке внутренних AI-инструментов (расчёт стоимости для аренды, чат-бот для бронирований и т.д.).

## Итоговая приоритизация для промпт-библиотеки заказчика

**Топ-3 файла по ценности для копилки промптов:**
