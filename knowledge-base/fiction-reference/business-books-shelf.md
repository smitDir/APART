# Полка бизнес-литературы (из загруженных FB2)

Все три книги — легитимная бизнес-нонфикшн литература, не относится к художественной прозе. Читать целиком не требовалось для каталогизации; при необходимости конкретных техник — открывать точечно по оглавлению.

1. **«Сарафанный маркетинг»** — Энди Серновиц (пер. Т. Мамедова, изд. МИФ, 2012). Практическое руководство по генерации органических рекомендаций/сарафанного радио вокруг бренда. → Полезно для контент-стратегии всех 7 направлений (органическое продвижение без бюджета на рекламу).
2. **«Вы или хаос»** — Александр Фридман (изд. Добрая книга, 2015). Управленческое планирование, устранение операционного хаоса в компании. → Полезно при масштабировании с одного направления (Apart) на семь.
3. **«СПИН-продажи»** — Нил Рекхэм (изд. МИФ, 2008). Классическая методология крупных B2B-продаж (Situation-Problem-Implication-Need-payoff). → Это та же модель SPIN, что уже встретилась в шаблоне «Свадебное агентство» (см. `sales-bot-templates/`) — источник этой техники.

Оригинальные файлы — у пользователя (fb2), не хранятся в репозитории.
