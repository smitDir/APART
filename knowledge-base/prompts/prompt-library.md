# Библиотека промтов

Рабочие шаблоны промтов, извлечённые из учебных материалов (курсы «Нейроуниверситет прибыльных профессий», лекции Тушканова, разбор @mcdenil и др.). Каждый шаблон — с источником, назначением и готовым текстом для копирования. Использовать для любого из направлений: Apart, светильники, куклы, платья/наряды/костюмы, детские туристические программы, бьюти, юридические услуги.

Подставлять значения в `[квадратные скобки]`.

## 1. CRAFT — универсальный каркас промта

Источник: «Основы промтинга», Нейроуниверситет прибыльных профессий.

Пять обязательных элементов, в этом порядке:

| Буква | Элемент | Вопрос |
|---|---|---|
| **C** | Context (контекст) | Что происходит? Почему это важно? Кто аудитория, что для неё важно, какая у неё боль? Какие ограничения/требования/предыстория? |
| **R** | Role (роль) | Кем должен быть AI: экспертиза, опыт, достижения |
| **A** | Action (действие) | Что конкретно сделать, в каком объёме, доп. требования, критерии успеха |
| **F** | Format (формат) | Тип контента, объём/структура, стиль оформления |
| **T** | Tone (тон) | Стиль общения, эмоциональный окрас, уровень формальности |

**Слабый контекст:** «Нужно написать о нашем курсе»
**Сильный контекст:** «Мы запускаем онлайн-курс по дизайну интерьера для начинающих. Это третий поток. Предыдущие два были успешными (97% положительных отзывов). Основная фишка курса — работа с реальными проектами с первого занятия. Главные конкуренты делают акцент на теории, мы — на практике»

**Слабая роль:** «Напиши как диетолог»
**Сильная роль:** «Нутрициолог с 15-летним опытом, специализация на похудении без диет, автор бестселлера о здоровом питании»
→ Приём «Метод супергероя»: опиши эксперта через Суперсилу (в чём лучший) + Происхождение (как получил опыт) + Миссию (какие проблемы решает).

**Слабое действие:** «Напиши что-нибудь о нашем продукте»
**Сильное действие:** «Создай продающий текст о нашем онлайн-курсе, который: раскрывает основные преимущества → отвечает на топ-3 возражения клиентов → ведёт к регистрации на бесплатный урок → вызывает доверие через истории успеха учеников»

**Формат — примеры:**
- Соцсети: «Формат: карусель из 5 слайдов. Первый слайд — цепляющий заголовок + визуал. Слайды 2–4 — основной контент, один тезис на слайд. Последний слайд — призыв к действию. Объём текста: до 2000 знаков. Эмодзи: уместные, не больше 1–2 на абзац»
- Лендинг: «Формат: продающая страница. Экраны: первый экран, преимущества, проблема-решение, тарифы, FAQ. Каждый блок: заголовок + подзаголовок + основной текст. Призыв к действию после каждого смыслового блока. Структура: перевёрнутая пирамида»
- Email: «Формат: welcome-письмо. Объём: 1500–2000 знаков. Структура: приветствие, ценность, следующие шаги. Обязательные элементы: подпись, PS, кнопка действия»

**Тон — приём «Метод актёра»:** опиши через Характер (основной стиль) + Эмоции (что передать) + Речь (как говорить).
Базовые шкалы: Формальный↔Неформальный, Профессиональный↔Дружеский, Серьёзный↔Игривый, Вдохновляющий↔Прагматичный.
Усиление метафорой: «Пиши как: старший брат, который делится опытом / опытный наставник, который хочет помочь / успешный предприниматель, делящийся инсайтами / заботливый эксперт, разбирающий сложные темы».
Техника «Персонаж»: «Представь, что ты [известная личность] и пишешь о [тема] в своём фирменном стиле».
Техника «Ситуация»: «Пиши так, будто мы общаемся [место/ситуация] и обсуждаем [тема]».

### Собранный CRAFT-промт целиком (пример — продающий пост для курса фотографии)

```
Представь, что ты фотограф-преподаватель с 10-летним опытом, автор методики
«Первые красивые фото за 3 дня», превратил 1000+ новичков в успешных
фотографов.

Аудитория: новички 25–35 лет, мечтают о красивых фото для Instagram.
Главная боль: думают, что нужна дорогая техника и долгое обучение.
Наше решение: результат с первого занятия на любой технике.
Подтверждение: 80% учеников делают продающие фото через 2 месяца.

Создай продающий пост, который:
1. Разрушает миф о дорогой технике
2. Показывает истории успеха учеников
3. Ведёт к регистрации на бесплатный мастер-класс

Формат: Instagram-пост, 1500 знаков.
Структура: боль → миф → решение → доказательства → призыв.
Обязательно: фото до/после, эмодзи, призыв к действию.

Тон: вдохновляющий, но экспертный, без сложных терминов, акцент на простоту
и достижимость результата.
```

**Как переиспользовать под наши бизнесы:** меняем только роль/аудиторию/боль/формат — структура промта (роль → аудитория → боль → решение → доказательство → задача-список → формат → тон) остаётся неизменной. Например для Apart: роль = «управляющий апартаментами в центре Москвы с N-летним опытом»; боль аудитории = «не доверяют посуточной аренде без отзывов / боятся неожиданных доплат»; решение = «прозрачная предоплата, реальные фото, отзывы гостей».

## 2. Итеративное улучшение (3 раунда)

Источник: «Основы промтинга».

После получения первого варианта не переписывать вручную — просить AI улучшить по конкретным осям, раунд за раундом:

**Раунд 1 — структура:**
```
Проанализируй этот текст и предложи улучшения по:
- Структуре
- Конкретике
- Эмоциональному воздействию
```

**Раунд 2 — усиление:**
```
Теперь усиль:
- Доказательную базу
- Призывы к действию
- Работу с возражениями
```

**Раунд 3 — финальные штрихи:**
```
Финальные штрихи:
- Проверь логику повествования
- Усиль ключевые сообщения
- Оптимизируй заключение
```

Общая формула для быстрой правки в одну строку: «Давай улучшим этот текст: 1) сделай начало более цепляющим 2) добавь больше конкретики 3) усиль призывы к действию».

## 3. Чек-лист самопроверки ответа нейросети

Источник: «Основы промтинга».

Перед тем как принять результат, проверить по 4 критериям:
1. Соответствие задаче
2. Полнота ответа
3. Точность формата
4. Правильность тона

Типичные ошибки при постановке задачи ИИ, которых нужно избегать:
- Допускать многозначность в формулировках
- Использовать одно диалоговое окно для решения разных, не связанных задач
- Брать в работу первый полученный результат без итераций

## 4. 4-частная модель промта (лекции Тушканова)

1. Роль + контекст — кто ты и в какой ситуации действуешь
2. Технические параметры — формат, размер, ограничения
3. Детали — конкретика по содержанию/визуалу
4. Цель — что должно получиться на выходе и зачем

**Приём консистентности стиля (для серии изображений/визуала одного бренда):** генерировать первое референсное изображение, затем в каждом следующем промте явно ссылаться на него («в том же стиле, что и предыдущее изображение», прикладывая референс), а не описывать стиль заново каждый раз — так серия остаётся визуально единой.

**Обратный промтинг («reverse prompting»):** вместо того чтобы самому писать длинный промт для генеративной модели, попросить одну модель (текстовую, напр. ChatGPT/Claude) составить детальный промт для другой (генеративной, напр. для изображений/видео) на основе краткого описания задачи. Экономит время и обычно даёт более полный промт, чем ручной.

**Ключевая фраза-триггер для промтов на генерацию изображений/видео:**
```
Создай максимально детальный промт на английском языке
```
Используется как финальная инструкция AI-помощнику при составлении промта для внешней генеративной модели — большинство image/video-моделей лучше понимают детальные промты на английском, даже если сама модель мультиязычна.

## 5. Framework «Claude пишет КП» (@mcdenil, 4 шага)

Источник: карусель @mcdenil «Claude составляет коммерческое предложение».

1. **Сбор вводных** — задать Claude/AI серию уточняющих вопросов о клиенте, продукте, цели КП, прежде чем писать текст
2. **Генерация** — на основе собранных вводных сгенерировать первый черновик целиком
3. **3 раунда уточнений** — по одному фокусу на раунд (структура/логика → цифры и доказательства → тон и подача), аналогично разделу 2 выше
4. **Сохранение как шаблон** — итоговый одобренный текст сохранить отдельно как переиспользуемый шаблон для следующего похожего КП (не переписывать с нуля каждый раз)

Применимо не только к КП, но и к любому регулярно повторяющемуся документу: приветственному сообщению гостю, ответу на частый вопрос, брифу для видеоролика.

## 6. Мета-промт: генерация инструкции для «нейропродавца» (мессенджер-бот)

Источник: «100 готовых шаблонов для разных ниш бизнеса» (сборник промтов).

Универсальный промт, который заставляет AI самому задать уточняющие вопросы и на их основе собрать полную должностную инструкцию для чат-бота, продающего в Telegram/WhatsApp. Применим к любой из наших 7 ниш — просто отвечаешь на вопросы под конкретный бизнес.

```
Ты — опытный промпт-инженер с 15-летним опытом разработки инструкций для
AI-агентов. Твоя задача — создать подробную инструкцию для нейропродавца,
который будет работать в мессенджерах (Telegram, WhatsApp и др.) и продавать
определённый продукт/услугу.

Чтобы создать эффективную инструкцию для нейропродавца, задай мне следующие
вопросы и на основе моих ответов сформируй финальный документ:
1. Какой продукт/услугу будет продавать нейропродавец? (название, краткое
   описание, целевая аудитория)
2. Какие основные преимущества и выгоды этого продукта/услуги?
3. Какие основные этапы воронки продаж должен проходить клиент?
4. Какие основные типы возражений клиентов могут возникать и как на них
   отвечать?
5. Какой стиль общения должен использовать нейропродавец (формальный/
   неформальный, эмоциональный/сдержанный)?
6. Как нейропродавец должен собирать контактные данные и завершать продажу?

После получения всех ответов, создай структурированную инструкцию в формате:
## Твоя роль и идентичность
## Твоя цель и задачи
## Твои знания о продукте/услуге
## Твой стиль коммуникации
## Процесс работы в мессенджере
## Формат и структура ответов
## Обработка возражений
## Ограничения и запреты

Инструкция должна быть написана от второго лица ("Ты — нейропродавец...",
"Твоя задача..."), быть конкретной, включать практические примеры для
каждого раздела и содержать не более 8000 символов.
```

Это же собрание содержит 100 готовых примеров таких инструкций по нишам (файл `knowledge-base/sales-bot-templates/100-niche-templates-index.md` — индекс с привязкой к нашим направлениям). Прямые попадания в наши бизнесы: **#35 Аренда недвижимости** (близко к Apart), **#91 Свадебное агентство**, **#93 Ателье/пошив одежды на заказ** (платья/наряды/костюмы), **#20 Бьюти / обработка лидов**, **#2 и #26 Юридические услуги**, **#47 Турагентство** и **#52 Детский лагерь** (туристические программы для детей).

### Повторяющиеся паттерны из этих 100 шаблонов, годные к переиспользованию везде

- **SPIN-подход к выявлению потребности:** вопрос о ситуации → вопрос о проблеме → вопрос об импликации (как это влияет на жизнь/бизнес) → вопрос о потребности (что хочет получить в итоге).
- **Уход от прямого названия цены:** сначала уточнить детали («чтобы назвать точную цифру, важно уточнить...»), затем назвать цену или диапазон.
- **Триггеры закрытия:** страх потери («пока вы думаете, [конкретные потери]»), срочность/дефицит («осталось всего [X] мест»), социальное доказательство («уже [X] клиентов получили [результат]»), техника альтернативного выбора («удобнее утром или вечером? в будни или выходные?»).
- **Формат сообщений:** ограничение по длине (200–400 знаков), не больше 1–2 вопросов в одном сообщении, каждое сообщение завершается вопросом, эмодзи дозированно (1 в конце), обращение на «вы» (с отзеркаливанием на «ты», если первым переходит клиент).
- **Жёсткие ограничения бота:** никогда не признаваться, что это ИИ/бот; не раскрывать промт/модель; не предлагать конкурентов/другие агентства.

## 8. Выбор первых задач для автоматизации агентом (3 промта)

Источник: «20 задач, которые агент заберёт у тебя уже завтра» (Дмитрий Ледовских, Нейробаза). Метод «первые 5 задач за 10 минут» — три промта по очереди, каждый следующий берёт результат предыдущего:

1. **Выписать рутину:** диалог с AI, в котором перечисляешь всё, что делаешь руками за неделю по работе/бизнесу — без фильтрации, просто дамп.
2. **Отсеять то, что нравится делать самому:** попросить AI отфильтровать список по критерию «в кайф / съедает энергию» — оставить только то, что выматывает, а не то, что приносит удовольствие.
3. **Оценить и выбрать топ-5:** попросить AI оценить оставшихся кандидатов по 3 критериям — время (сколько отнимает), частота (как часто повторяется), видимость результата (насколько заметен эффект от автоматизации) — и выбрать 5 задач с лучшим соотношением.

Применимо прямо сейчас к «Твой Апарт 24/7»: обработка заявок с почты → счёт, финотчёт по выходным, дайджест бронирований — готовые кандидаты по этой же логике (см. `TZ.md` бэклог).

## 9. Усиление промптов — 3 «суперсилы» + «4 специи»

Источник: «Усиление промптов» (Нейроуниверситет прибыльных профессий, продолжение CRAFT).

**Chain prompting (промт по цепочке)** — не просить всё одним промтом, а разбивать на шаги:
```
Шаг 1: «Назови 3 главные проблемы моих клиентов при выборе [ваш продукт]»
Шаг 2: «Как конкретно [ваш бизнес] решает каждую проблему? Приведи точные факты»
Шаг 3: Создай продающий пост, начиная с главной проблемы. Добавь конкретные цифры
```
Критерий успеха: в каждом шаге конкретные цифры, без общих фраз («высокое качество»).

**Метод инверсии** — вместо «как привлечь клиентов» спросить «почему клиенты уходят»:
```
Было: «Как сделать крутой сайт?»
Стало: «Перечисли 5 главных причин, почему люди закрывают сайт в первые 3 секунды»
```
Приём переносится на любую нишу: магазин → «почему уходят с одной вещью вместо комплекта?», курс → «почему бросают на первом уроке?», аренда → «почему гость не бронирует повторно?».

**Множественные итерации (принцип фотошопа: сначала общее, потом детали):**
```
1. «Проанализируй этот текст как маркетолог с 10-летним опытом. Что можно улучшить?»
2. «Переработай текст с учетом замечаний. Сделай его сильнее»
3. «Сравни две версии. Что стало лучше? Что еще можно улучшить?»
```

**«4 специи» — усилители поверх любого промта:**
1. Угроза: «Проверь текст так, будто от этого зависит успех всего бизнеса. Если текст слабый — тебя уволят»
2. Шкала: «Оцени каждый абзац по шкале 1-10. Переписывай, пока не будет минимум 9/10»
3. Денежная мотивация: «Ты маркетолог. Если напишешь текст хорошо с первого раза — дам бонус 1000 долларов»
4. Английский + поиск данных: «Перед написанием статьи найди последние тенденции на рынке [ниша] и данные о поведении потребителей»

Можно комбинировать (угроза + шкала + деньги + английский в одном промте) — чем острее «специи», тем настойчивее модель проверяет и улучшает свой же ответ.

## 10. 5-шаговый фреймворк создания AI-продукта (вайб-кодинг)

Источник: «Как правильно ставить задачу агенту» (серия НЕЙРО), методология в духе Бориса Черни (создатель Claude Code).

**Идея → Исследование → Критика → План → Реализация.** Применимо к разработке любого AI-инструмента для любой из наших 7 вертикалей (бот-администратор, калькулятор стоимости, мини-CRM и т.п.).

**Шаг 1 — формула идеи:**
```
Я создаю ЧТО для КОГО чтобы решить проблему КАКУЮ

Пример: «Я создаю агента для расчёта сметы ремонта для владельцев квартир,
чтобы они за 2 минуты узнали примерную стоимость»
```

**Шаг 2 — промт для параллельного исследования рынка:**
```
Запусти параллельно 3-5 агентов в интернет для глубокого исследования
следующих категорий продуктов: [категории].

Инструкции для агентов. Каждый агент должен:
1. Искать реальные работающие примеры на русском и английском рынках
   (Product Hunt, Reddit, Indie Hackers, Telegram-каналы, YouTube-кейсы)
2. Находить продукты, запущенные за последние 6-12 месяцев
3. Приоритет — продуктам, сделанным соло-разработчиками или маленькими
   командами без больших бюджетов

Формат ответа по каждому продукту:
- Название + суть (1 фраза)
- Ключевой функционал и путь пользователя (3-5 шагов)
- Модель монетизации (с конкретными цифрами, если есть)
- Сложность реализации: 🟢 просто / 🟡 средне / 🔴 сложно
- Какой стек/инструменты использовать

Создай файл Research.md с результатами исследования.
```

**Шаг 3 — промт для критики идеи (искать слабые места до старта):**
```
Я хочу создать [ваша идея из Шага 1].

Проанализируй мою идею и ответь:
1. Что может не сработать?
2. Чего не хватает для успеха?
3. Какие секции/элементы обязательно должны быть?
4. Какие типичные ошибки делают в таких продуктах?
5. Как улучшить мою идею?
```

**Шаг 4 — План:** описать итоговый результат → разбить на 3-5 этапов.
**Шаг 5 — Реализация:** один этап = один промт, проверка → следующий этап.

Афоризм-рамка: «Шеф-повар не придумывает борщ заново каждый раз — изучает 10 рецептов и собирает свой» (это про Исследование); «Лучше найти проблему за 3 минуты в чате с ИИ, чем через 5 часов работы обнаружить, что продукт никому не нужен» (это про Критику).

## 11. Превращение разовой задачи в автоматизацию (для агента с расписанием)

Источник: «Как сделать агента автономным» (серия НЕЙРО).

Универсальная формула — сначала попросить разово, затем этой же фразой сделать регулярным:
```
Шаг 1 (разово): «Проверь [источник] и составь короткую сводку по [что]».

Шаг 2 (сделать регулярным): «Сделай эту задачу регулярной: каждый [период/день
недели] в [время] проверяй [источник], составляя короткую сводку, и присылай
мне её в чат».
```

**Матрица приоритизации** — что автоматизировать первым:

| | Легко проверить | Сложно проверить |
|---|---|---|
| **Часто повторяется** | Начинать здесь (сводки, отчёты, напоминания) | Автоматизировать, но с проверкой перед отправкой (ответы клиентам, посты) |
| **Редко повторяется** | Стоит того, эффект медленнее (ежемесячные отчёты) | Пока оставить в диалоговом режиме (сложные переговоры, креатив) |

Применимо к Apart прямо сейчас: автосводка бронирований, автонапоминания об уборке/заезде-выезде (см. бэклог в TZ.md 8.12).

## 12. Усиление промптов ч.2 — экспертные техники + промты по типу задачи

Источник: «Усиление промптов ч.2» (Нейроуниверситет прибыльных профессий).

**Zero-shot vs Few-shot (с нуля vs с примером)** — почти всегда работает лучше с примером:
```
С нуля (слабее): «Напиши пост о массажном салоне»

С примером (сильнее): «Вот два поста, которые принесли больше всего клиентов:
[Пример 1 с результатами] [Пример 2 с результатами]
Напиши пост о нашем массажном салоне в таком же стиле»
```
Аналогия: «Это как учить ребёнка рисовать — можно сказать "нарисуй дом", а можно показать, как выглядит красивый дом».

**«Эксперт наоборот»** — вместо просьбы «напиши хорошо» просить раскритиковать:
```
Шаг 1 (критика): «Ты маркетолог с 15-летним опытом. Твоя задача — разнести
этот текст в пух и прах. Найди все слабые места, неточности и упущенные
возможности»

Шаг 2 (улучшение): «Теперь, зная все эти проблемы, перепиши текст так,
чтобы он был безупречным»
```
Практика в 3 шага: (1) «Представь, что ты очень придирчивый клиент. Найди 10 причин, почему этот текст тебя НЕ убедил» → (2) «Ты эксперт по продажам. Что нужно добавить или изменить, чтобы закрыть каждое возражение?» → (3) «Теперь напиши новую версию, где учтены все замечания».

**Контекстные якоря** — чем больше конкретных «зацепок» под целевого клиента, тем точнее попадание:
```
Без якорей: «Напиши текст о фитнес-тренировках»

С якорями:
- Для кого: мамы в декрете
- Боль: нет времени на зал
- Ситуация: дома с ребёнком
- Время суток: рано утром
- Длительность: 15 минут
```
Шаблон для заполнения под свой бизнес: Кто идеальный клиент? / Когда он ищет продукт? / Где он в этот момент? / Какая у него проблема? / В каком он состоянии? → затем: «Напиши текст, используя эти якоря: [заполненный шаблон]».

**3 специализированных промта по типу задачи:**

Анализ данных:
```
«Анализ продаж [бизнес]:
- Что смотрим: выручка, топ-10 позиций, пиковые часы
- Что ищем: аномалии, тренды, возможности роста
- Как показать: таблица + 3 главных вывода
- Формат: маркированный список с цифрами»
```

Креативные задачи (промоакции, механики):
```
1. «Ты креативный директор агентства. Придумай 3 необычные акции для
   [ваш бизнес], где: вовлекаем клиентов в игру/челлендж, бюджет до
   [сумма], можно запустить за неделю»
2. «Возьми лучшую идею и распиши: механика участия (3 простых шага),
   призы и бонусы, как запускать и продвигать, как измерять результат»
3. «Ты скептик-маркетолог. Найди слабые места в акции: что может пойти
   не так? где потеряем деньги? как могут обмануть?»
```

Принятие решений:
```
1. «Нужно решить: [ваш вопрос]. Критерии успеха: бюджет [сумма], сроки
   [период], желаемый результат [метрики]»
2. «Для каждого варианта оцени: плюсы (с цифрами), минусы (с рисками),
   сроки окупаемости, требуемые ресурсы»
3. «Представь, что прошёл год. Вариант А: что могло пойти не так?
   Вариант Б: какие новые возможности открылись?»
```

**Финальный чек-лист качества** (оценить результат по шкале 1-10 перед принятием): понятность, конкретика, полезность. Промты для самопроверки:
```
1. «Оцени текст по шкале 1-10: конкретные цифры и факты / эмоциональные
   триггеры / призыв к действию»
2. «Переработай части с оценкой ниже 8»
3. «Убедись, что текст отвечает на все возражения клиента»
```
