# Черновик системного промта Apart-бота (`9ed0e38d`)

Это оригинальный черновик персоны AI-ассистента арендодателя, который пользователь присылал раньше. Сверено с текущим кодом (`server/src/ai/knowledgeBase.js`, `server/src/ai/gemini.js`) — **большая часть уже реализована**:

- Тарифная сетка со скидками за длительность — реализована через `pricing_tiers` в БД (числа в черновике были примером, сейчас берутся из реальных данных).
- Аванс 30% + залог — реализовано (`deposit_percent`, `security_deposit`).
- Бюджетная альтернатива (комната вместо апартаментов) — реализована, с той же логикой «предлагать только если гость сам просит подешевле».
- Тон/стиль «частный хозяин, не агентство», отсутствие давления, направление к менеджеру при сомнении — реализовано в `buildSystemPrompt`.
- Политика отмены (>72ч — полный возврат, позже — удержание 50%) — уже зафиксирована в тексте persona (см. TZ.md §201), но код логики отмены/возврата ещё не написан (открытая задача TZ.md §8.6).

**Не перенесено в код явно** (можно добавить одной строкой в system prompt, если понадобится):
- Явный запрет запрашивать паспортные данные и полные реквизиты карт в чате (152-ФЗ) — сейчас это только общий принцип на уровне процесса оплаты через YooKassa, не прописан как явная инструкция для AI внутри диалога.
