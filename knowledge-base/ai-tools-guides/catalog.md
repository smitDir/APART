**Название:** Шпаргалка — карта выбора модели Claude
**Автор:** Роман Сухов (@sukhov_live, 24-ai.ru)

Что внутри:

**Категория:** (a) общая инфраструктурная памятка — практично держать под рукой при работе с Claude Code для любого из 6 бизнес-направлений.

## 2. 0d31c91a-GLM5.2_ustanovka_cherez_terminal.pdf
**Название:** GLM-5.2 в твоём терминале за 5 минут (бесплатный гайд, 24 AI / Роман Сухов)

Что внутри:
- Установка открытой модели GLM-5.2 (Z.ai, MIT-лицензия, контекст 1М) через OpenCode + OpenRouter, рядом с Claude Code
- Пошагово: `curl -fsSL https://opencode.ai/install | bash` → `opencode auth login` → выбрать OpenRouter → `/models` → `z-ai/glm-5.2` → variant `xhigh`
- Бонус: алиас `ccg()` в `~/.zshrc`, чтобы гонять GLM прямо внутри Claude Code (нужен отдельный ключ Z.ai GLM Coding Plan, не OpenRouter)
- Цены: OpenRouter $1.40/$4.40 за 1M (тесты); Coding Plan Lite ~$16/мес, Pro ~$65/мес, Max ~$144/мес
- Предупреждение: дешевле за токен ≠ дешевле за результат — GLM может сжигать больше токенов на ту же задачу

**Категория:** (a) общая инфраструктура — полезно как запасной/более дешёвый вариант модели для рутинных задач, но не критично для бизнес-контента.

## 3. 228fb561 — "Второй мозг на трёх папках" (личная wiki через Claude Code + git)

Что внутри:
- Метод превращения свалки заметок в самообновляющуюся личную wiki без Notion/Obsidian
- Архитектура: 3 папки — `raw/` (сырьё, не трогать), `wiki/` (статьи по темам со связями [[имя-файла]]), `outputs/` (ответы на вопросы)
- Один файл `CLAUDE.md` с правилами игры (тематика, что можно/нельзя, формат статей, запрет на удаление из raw/ и додумывание фактов)
- Примеры промптов: собрать статьи по теме, сравнить подходы, ежемесячная "ревизия" wiki (Claude ищет противоречия/дубли/устаревшее и отчитывается, не правит сам)
- Обоснование "почему не Notion/Obsidian": .md открывается везде, дружит с git, ничего не ломается обновлениями

**Действие:** этот метод прямо применим к текущей задаче организации знаний для 6 бизнес-вертикалей — можно взять шаблон CLAUDE.md и структуру raw/wiki/outputs как основу.
**Категория:** (a) общая инфраструктура/методология — весьма актуально и применимо прямо сейчас.

## 5. 9e2e8159-__________Codex.pdf
**Название:** Установка Codex (Сухов Live) — гайд к ролику

Что внутри:
- Codex — вайб-кодинг агент от OpenAI, два способа установки: CLI и расширение VS Code
- Предпосылки: Node.js + npm, аккаунт ChatGPT Plus (или ключ OpenAI API)
- CLI: `npm install -g @openai/codex` (важно: именно `@openai/codex`, не просто `codex` — есть несвязанный старый пакет), запуск командой `codex`, вход через ChatGPT или ключ API
- VS Code: поиск расширения "Codex" от издателя OpenAI (id `openai.chatgpt`), либо `code --install-extension openai.chatgpt`. Работает и в форках (Cursor, Windsurf). Конфиг в `~/.codex/config.toml`
- Три режима доступа: запрос разрешений на каждое действие / автопроверка / полный доступ (Agent Full Access) — рекомендация начинать с режима запроса разрешений

**Категория:** (a) общая инфраструктура — альтернативный агент к Claude Code, полезно знать команды установки на будущее.
