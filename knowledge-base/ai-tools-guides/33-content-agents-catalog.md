# «33 агента, чтобы делать контент» — каталог + разбор применимости

Источник: лид-магнит `edeceb21-*.pdf` к платному практикуму «Миллион на вайбе» (8–9 июля). Список реальных open-source репозиториев на GitHub, без нелегального содержимого — но это рекламный материал для продажи курса, не нейтральный гайд, поэтому сам список честный, а рамка вокруг него — маркетинг.

**Общий вывод: не ставить всё подряд.** Большая часть решает задачи, которые либо уже закрыты в нашей архитектуре проще, либо требуют GPU-мощностей, которых на нашем VPS нет и не нужно (RunComfy уже закрывает генерацию медиа через облако).

## Разбор по категориям

### Голос и озвучка — единственное, что стоит подключить прямо сейчас
- **Whisper** (openai/whisper, ★104k) — расшифровка речи в текст. **Это прямое попадание в уже существующую задачу бэклога** (TZ.md 8.12: «Голосовые сообщения от гостя — транскрибация через Whisper»). Стоит подключить как API-вызов (через OpenAI API или Groq — быстрый бесплатный инференс Whisper) в `server/src/bot/index.js` для обработки голосовых сообщений гостей, а не разворачивать self-hosted модель на VPS.
- OpenVoice / Coqui-TTS (клонирование голоса/синтез речи) — не нужны для Apart сейчас, это про генерацию озвучки для контента (подкасты/видео), не про распознавание голоса гостя.

### Ресёрч и поиск тем — концептуально полезно, устанавливать не нужно
- firecrawl, browser-use, gpt-researcher, Agent-Reach — это инструменты для ИИ-агента, которые я (Claude) и так могу использовать по смыслу задачи (веб-поиск, чтение сайтов) без необходимости их устанавливать на сервер. Полезны как концепция «агент-разведчик» — уже зафиксирована в `knowledge-base/courses/neiro-and-tushkanov-lectures.md`.

### Видео и Reels/Shorts, Картинки — НЕ устанавливать на VPS
- MoneyPrinterTurbo, CogVideo, ShortGPT, AI-Shorts-Generator, ComfyUI, Fooocus — все требуют GPU для реальной работы (видео/image-генерация). У нас эта задача уже закрыта через **RunComfy** (облачный GPU-сервис, уже используется в `content/publisher.js`/README) — самостоятельный хостинг этих моделей был бы дублированием и потребовал бы совсем другой (дорогой) VPS-спеки с видеокартой.
- MidJourney-Reference — просто справочник промтов, не софт; можно смотреть точечно при генерации визуала под конкретный пост.

### Автоматизация соцсетей / no-code связки — НЕ менять на них уже готовое
- Activepieces, Eliza, postiz, Mixpost, n8n, Flowise, Dify, Langflow — это альтернативные универсальные системы для того, что у нас уже сделано штучно и проще: `scheduled_posts` + недельное утверждение + `publisher.js` (Telegram/YouTube). Переход на генерический инструмент сейчас — шаг назад по принципу «не усложняй то, что уже работает». Держим в уме как вариант, если понадобится единый конвейер сразу под все 7 направлений и станет тесно в самописном решении — но не сейчас.
- n8n у нас уже используется отдельно (шаблоны из прошлых загрузок — легал-бот, LinkedIn-автоматизация), это не про Apart-бэкенд конкретно.

### Фреймворки для сборки агентов (CrewAI, AutoGen, LangGraph, Agno) — это про то, как Я работаю, не про продукт
Роль-агенты/мультиагентные системы — та же идея, что и параллельные фоновые агенты, которых я уже использую в этой сессии (Explore/general-purpose и т.д.) для разбора материалов. Устанавливать их в apart-server незачем — это фреймворки для *построения своих* агентов с нуля, а не библиотеки, которые встраиваются в Express-бэкенд.

### MCP и подключения
firecrawl-mcp, Figma-Context-MCP, awesome-mcp-servers — MCP-серверы для Claude Code лично для вас как разработчика/оператора (не для продакшн-бэкенда Apart). Если понадобится конкретный MCP (например, Figma — если будете делать дизайн-макеты) — подключается по необходимости через `claude mcp add`, не «все 90k+ каталога awesome-mcp-servers».

## Итоговая рекомендация

Из 33 позиций **реально стоит внедрить одну прямо сейчас — Whisper для голосовых сообщений гостя** (уже в бэклоге). Остальное — либо уже закрыто (RunComfy, наш content-pipeline), либо избыточно для текущего масштаба, либо не про продакшн-сервер вообще, а про то, как я организую свою работу как ассистент. Список сохранён здесь как справочник — если один из 6 будущих бизнес-направлений упрётся в конкретную задачу (например, потребуется self-hosted TTS для куклы-озвучки видео) — можно вернуться и взять точечно нужный инструмент.
